# Blazor Spreadsheet Performance Metrics

This sample showcases performance analysis across the Blazor Spreadsheet component, including workbook loading, editing, formula calculation, sorting, filtering, and large dataset handling.

## Prerequisites

Before running the sample, ensure that the following software is installed:

- .NET SDK (Latest LTS version recommended)
- Visual Studio 2022 or later with the ASP.NET and web development workload

## Running the Sample

### Using the Command Line

Restore project dependencies:

```bash
dotnet restore
```

Run the application:

```bash
dotnet run
```

After the application starts, open the URL displayed in the terminal in your browser.

### Using the Visual Studio UI

1. Open the solution in Visual Studio.
2. Set the web application project as the startup project, if required.
3. Click the **Run** button in the Visual Studio toolbar or press **F5**.
4. The application will build and launch in your default browser automatically.

After the application starts, you can interact with the Blazor Spreadsheet Web App in the browser.
