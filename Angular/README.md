# Angular Spreadsheet performance metrics
This sample showcases performance analysis across angular spreadsheet component such as data loading, editing, formula calculation, sorting, filtering, and large dataset handling.

## Running the Sample

### Install Dependencies

```bash
npm install
```

### Run the Sample

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.
